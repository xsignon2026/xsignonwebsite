# Requests for shared files (Version 2)

ChatGPT never edits the shared files listed in `docs/chatgpt-brief.md`. If you need a shared change (a design token, a header detail, a new package, a shared card variant, a schema field), add a request here and carry on with another page. Claude answers the same day and moves each answered request to "Done".

Format of a request:

- **Page:** which page needs it
- **Need:** what you need changed, and where
- **Prototype:** what the prototype does (view name, the CSS rule or the section)
